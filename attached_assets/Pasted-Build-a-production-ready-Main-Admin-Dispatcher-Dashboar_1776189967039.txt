Build a production-ready Main Admin Dispatcher Dashboard for Green’s Landscape and Pressure Washing.

Goal:
This is the master control center for the business owner, head dispatcher, or operations manager. It should control the full business: leads, quotes, jobs, crews, invoices, communications, automation, reporting, user management, and escalations from sub dispatchers.

Tech stack:
- Next.js
- React
- Tailwind CSS
- TypeScript
- PostgreSQL
- Prisma ORM
- Role-based auth
- Replit-ready deployment

Create these roles:
- ADMIN
- OWNER
- SUB_DISPATCHER
- CREW_MEMBER
- OFFICE_STAFF

Main Admin permissions:
Allowed:
- full access to all operational pages
- create, edit, delete records
- manage users and permissions
- manage Stripe and Twilio settings
- manage integrations
- manage pricing rules
- manage service areas
- manage automation rules
- view full financial reports
- approve escalations
- override schedules
- export reports
- manage templates and campaigns
- create and archive crews
- view audit logs

Build these pages for the Main Admin Dashboard:

1. Executive Overview Dashboard
Show:
- total leads this week
- total quotes sent
- quote acceptance rate
- jobs scheduled today
- jobs completed this week
- unpaid invoices
- revenue this week
- revenue this month
- average job value
- missed calls
- response time
- reviews gained this month
- reactivation campaign performance

Add visual sections for:
- revenue trend
- lead source breakdown
- service type breakdown
- pipeline value
- crew utilization
- overdue invoice alerts

2. Lead Command Center
Features:
- full searchable table
- filter by date, status, service type, area, source, assigned user
- bulk actions:
